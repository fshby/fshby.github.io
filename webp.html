说明

· 转换规则：照片.png → 照片.webp，照片.jpg → 照片.webp，仅替换扩展名后缀，不带原扩展名。
· 同名碰撞检测以最终文件名为准，发生冲突时追加序号（如 照片.1.webp），不会互相覆盖。
· 目录写入依赖 File System Access API，Chrome / Edge 最新版支持最佳；Firefox 与 Safari 下输出请使用「导出为 ZIP」。
· 目录选择期间若浏览器提示权限，请允许；长时间运行后权限可能过期，可点击「仅重试失败项」重新授权。
· GIF / APNG 动图经 canvas 编码只会保留第一帧；SVG 与部分 HEIC/AVIF 可能无法解码，会列入失败项。
· 调试版 v2026-04-23d：扫描阶段不再读取文件内容，仅记录句柄；每个阶段均打印耗时，便于定位卡顿。
